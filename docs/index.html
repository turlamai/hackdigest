三层 Digest，把英文墙拆掉

翻译只是地基。HackDigest 用 AI 把 HN 最难啃的部分变成两分钟中文阅读。

📄

文章 TL;DR

HN 链接的原文动辄五千词英文。一键压缩成几段中文摘要，先知道值不值得读，再决定要不要读。

💬

评论区观点提炼

HN 的精华在评论区。八百条英文回复，提炼成正反双方核心论点、值得一看的发言、以及社区的最终倾向。

☕

每日晨报

今早的首页变成两分钟中文晨读：按主题分组、每条一句话为什么值得看，喝口咖啡决定今天深读哪几篇。

快、透明、可回溯

信息流只是入口。HackDigest 把阅读体验钉在三件事上：手不离键盘、译文不覆盖原文、处理进度看得见。

⌨️

键盘一等公民

jk 选择 · 1–6 切换信息流 · t 翻译标题 · shiftt 整页 / 全部评论 · d 摘要 · s 书签 · / 搜索 · ? 速查

手不离键盘完成全流程，鼠标随时可用；按 ? 呼出速查表，新键位一屏学会。

📖

译文与原文并列

翻译永不覆盖原文：标题译文随行显示，评论逐条翻译，摘要展开即回原文。每条译文都标注来源与状态（机译），可追溯、可回看。

🔄

状态永不静默

翻译与摘要都有进行态与完成态徽标：按下即见「翻译中」，完成后「TL;DR 已生成」「机译」徽标常驻，后台任务始终可感知。

🔐

自带密钥，全功能免费

配置任意 OpenAI 兼容端点即解锁全部功能，应用本身免费开源。v0.4.0 起密钥默认存入系统钥匙串（Keychain / Credential Manager / Secret Service），不落明文。
