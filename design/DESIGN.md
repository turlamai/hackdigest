# HackDigest DESIGN.md — 视觉与交互契约（单一真源）

原型（`design/prototype/`）与实现（`apps/desktop/`）都遵循本文件；改视觉先改这里，再同步实现。
Tokens 提取自 `apps/desktop/src/styles.css` 现行值，保证原型 → React 实现零翻译成本。

## Brief（2026-11-10 试点）

- **目标**：非从零重设计。在既有暖纸色体系上做 HIG 级打磨；让「翻译 + 三种 digest」这个差异化主角在界面上站出来；界面达到可直接用于官网宣传的质量。
- **原型范围**（5 屏 × 亮/暗）：① Feed 主视图（英雄屏）② 故事详情 + TL;DR + 评论翻译态 ③ 每日摘要 ④ 设置（API key / 提供商 / 快捷键）⑤ 快捷键速查浮层。
- **Exit 条件**：5 屏关键状态齐（含空态/进行态）+ 交互逻辑定稿 + HIG 清单全过 + 用户评审通过。
- **不在范围**：新功能、路由/契约变更（不动 `glaze-schema.json`）、商业/定价 UI、新配色体系。

## 设计原则（HIG 内核）

- **内容至上**：chrome 退后，标题与译文是每个 row 的主角；装饰不与内容争注意力。
- **键盘一等公民**：j/k、1–6、s、t、r、d、/、? 全部有可见入口与提示，鼠标不嗨也能完整操作。
- **反馈及时**：翻译/摘要有进行态与完成态徽标，永不静默；后台任务可感知。
- **防错一致**：跨平台快捷键语义一致；破坏性操作需确认。
- **层级克制**：bg < raised < surface 三层足够；accent 只给交互与状态。

## Tokens（与实现 1:1）

| Token | Light | Dark | 用途 |
|---|---|---|---|
| `--bg` | `#faf9f7` | `#171512` | 画布 |
| `--surface` | `#ffffff` | `#201d19` | 卡片/浮层 |
| `--raised` | `#f3f1ec` | `#282420` | 悬浮/选中底 |
| `--line` | `#e7e3da` | `#322e27` | 分隔 |
| `--ink` | `#1f1d1a` | `#e8e4dc` | 主文字 |
| `--mute` | `#8a8578` | `#90897a` | 次级文字 |

| `--accent-soft` | `#faeee5` | `#33241a` | accent 弱底（徽标） |

- **字体**：`system-ui, -apple-system, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei"`；正文 15px/1.6，行标题 600，次级 13px，辅助 12px。
- **圆角**：窗口 12px · 卡片 8px · 控件 6px。**间距节奏**：4/8/12/16/24。**动效**：120ms ease，不过度。
- **语言**：界面文案跟随系统（zh-CN / en 双源，见 `src/i18n`）；内容翻译不替换原文，与原文并列可回溯。

## 组件词汇

`Sidebar`（feed 导航 1–6 + 每日摘要/书签/搜索/设置）· `StoryRow`（序号/标题/译文/元信息行/状态徽标）· `DigestCard`（TL;DR 卡）· `CommentTree`（缩进层级 + 翻译态）· `ShortcutsOverlay`（? 唤起）· `Toast`。

## 不变式

1. `accent` 只用于：当前选中、链接、进行态、主按钮；禁止大面积色块。
2. 层级靠 `raised`/`surface` 与 `line` 分隔，不用重描边、不用阴影堆叠表达层级。
3. 亮暗主题成对设计，不存在只有暗态的界面。
4. 译文永远标注来源与状态（机译/已校），摘要永远可展开回原文。
5. 键盘提示用 `kbd` 样式统一：`line` 底、`mute` 字、6px 圆角。
