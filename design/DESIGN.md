# HackDigest — 视觉与交互契约

本文件记录当前可编辑原型的视觉与交互基线。原型入口为 `index.html`；五个独立入口位于 `prototype/`，共用 `shared.css` 与 `app.js`。这些文件是浏览器内交互原型，不代表已接入产品引擎或模型服务。

## 本轮目标与边界

沿用既有暖纸色与橙色品牌，改善阅读层级，串联浏览、翻译、摘要、讨论与收藏。保持现有功能范围，不增加商业、付费或新模型服务能力。

五屏包括故事列表、故事详情、每日摘要、设置与快捷键。`index.html` 直接进入故事列表，不再以文件目录作为产品首页。各独立入口与首页使用同一套组件、数据和交互。

设计方向为安静、内容优先的阅读工具：少量强调色，明确的文字层级，轻量分隔，适中的信息密度。暖纸色与系统字体来自原有契约；本轮没有更换品牌体系。

原有浅色次级文字和橙色已加深，暗色次级文字已提亮，以提高可读性。颜色不单独承载状态：收藏使用文字或可访问名称，翻译带有明确的示例标记。

字体沿用系统字体栈：`system-ui, -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`。页面标题 26–32px，详情标题 24–32px，故事标题 16–17px，阅读正文 16px，辅助信息 12–13px。正文行高 1.65–1.85；详情内容最大宽度 800px。系统字体属于既有产品视觉语言，本轮继续沿用。

间距以 4/8px 为节奏；控件圆角 6px，内容面板 8px，浮层 12px。常规反馈 180ms，遵循系统减少动态效果偏好。图标统一为 24px viewBox 的线性 SVG，功能图标通过 `.od-icon` 统一尺寸与描边。

## 页面结构

### 故事列表

桌面使用侧栏、主列表和阅读辅助区。顶部保留全局搜索，页面标题解释当前 Feed；摘要入口与列表操作分层，避免多个主操作竞争。

默认双语展示以中文译文为主、英文原文为辅；也可选择只看译文或原文。未翻译故事保留英文，并提供翻译入口。来源、分数、讨论数与时间只出现一次。摘要入口可直接打开对应故事摘要。

热门、最新、最佳、提问、展示、招聘使用同一份示例数据进行排序或筛选，不暗示实时数据加载。搜索同时匹配中英文标题、来源与主题；清除搜索恢复当前分类。收藏列表从相同的收藏状态派生，取消收藏后立即更新。

### 故事详情

返回操作恢复来源页面与列表滚动位置。标题保留英文可回溯关系，文章摘要与讨论摘要通过明确的分段控件切换。

摘要必须标注演示来源，不能假称已经读取完整原文或全部评论。评论可逐条翻译或批量切换到预置译文，并通过 disclosure 展开对应英文。示例评论使用明确的示例身份，不借真实用户身份制造引语。

原始输入未提供文章 permalink，因此来源按钮明确命名为“访问来源网站”，只链接到已有域名首页，不伪造文章 URL。

### 每日摘要

按现有八条示例故事分组，数量由实际条目推导，不沿用原来“30 条精选”的虚拟总数。主题筛选支持查看全部或单一主题。每条可进入故事详情或收藏。摘要文案不再使用未核验的成本、吞吐和生产数据作为事实背书。

### 设置

分为模型与连接、阅读与翻译、外观与操作。提供商、目标语言、评论翻译上限使用原生选择控件；开关具备可访问名称和状态。

偏好在会话内立即应用，点击保存后尝试写入浏览器存储；存储不可用时使用内存状态。亮暗主题可跟随系统，也可手动切换。

API 密钥字段仅接受 `demo-key` 体验成功反馈，Ollama 演示可留空。密钥不保存、不发送，不提供真实网络测试，不宣称系统 Keychain 或真实服务连接已经实现。无效输入显示就近错误，未操作时不展示错误。

恢复默认使用确认浮层，不删除收藏。

### 快捷键

五个独立入口均可使用帮助浮层，快捷键页面也保留独立入口。浮层可关闭并返回触发控件。

| 操作 | 快捷键 |
|---|---|
| 上 / 下选择故事 | k / j |
| 打开选中故事 | Enter |
| 返回来源列表 | u / 左方向键 |
| 切换 Feed | 1–6 |
| 聚焦搜索 | / |
| 翻译选中标题 | t |
| 翻译当前列表 / 当前展示评论 | Shift+T，随上下文变化 |
| 打开故事摘要 | d |
| 收藏 / 取消收藏 | s |
| 每日摘要 | g 然后 d |
| 收藏列表 | g 然后 b |
| 刷新演示列表 | r |
| 帮助 / 关闭帮助 | ? / Esc |

输入框、选择控件与对话框内不触发后台阅读快捷键。原有提示中的未实现命令不继续作为承诺展示。

## 响应式与可访问性

宽屏保留阅读辅助区；中等窗口使用侧栏和主内容；窄屏将导航折叠为可展开菜单，摘要主题换行显示。页面使用正常文档流，无模拟桌面窗口的固定高度、交通灯或背景投影。

主操作具备可见键盘焦点。窄屏主要操作触达高度至少 44px。对话框使用原生模态语义，关闭后恢复焦点。空搜索与空收藏提供解释和下一步。原生 hidden 与关闭对话框规则保留。

## 原型与真实实现的界线

- 新闻、日期、票数与讨论数沿用示例数据，不代表实时抓取。
- 翻译与摘要使用预置文本；进行态仅演示交互反馈，不调用模型。
- 设置偏好只代表浏览器原型状态，不保证产品引擎已实现对应行为。
- 本轮交付 HTML、CSS、JavaScript 与本契约，没有生成截图、导出包或产品发布素材。
- 本轮未执行浏览器预览、自动化测试或三平台 WebView 验收；这些不应写为已完成。

产品实现继续遵守家族技术线约束：原型 JavaScript 仅作为浏览器 UI 演示。真实业务、服务连接与安全存储由产品引擎和对应平台契约负责，不能从本原型推断其已实现。
